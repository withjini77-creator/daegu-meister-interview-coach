# 대구 마이스터고 AI 면접 코치 (배포 준비용 시제품)

## 현재 포함된 것
- 5개 학교 선택 UI와 학교별 분야 설명
- 공식 홈페이지/모집안내 링크
- 연습 질문 유형 분류
- AI 피드백 화면 및 Vercel serverless API 코드
- AI API 키를 브라우저에 노출하지 않도록 서버 환경변수 사용

## 중요한 한계
이 프로젝트는 아직 인터넷에 배포된 사이트가 아닙니다. `index.html`을 컴퓨터에서 열면 화면은 볼 수 있지만, AI 피드백은 서버 API를 배포하고 API 키를 설정해야 작동합니다. 공식 기출 문항을 복제한 것이 아니며, 학교별 일반 연습 질문은 연습용으로 표시합니다. 반도체 학교는 공식 사이트에 적성소양 문제예시 메뉴가 있으므로 해당 원문을 확인한 뒤 별도 반영할 수 있습니다.

## Vercel 배포 요약
1. 이 폴더를 GitHub 저장소에 업로드합니다.
2. Vercel에서 해당 저장소를 새 프로젝트로 가져옵니다.
3. 프로젝트 Settings → Environment Variables에서 `OPENAI_API_KEY`를 설정합니다. 필요하면 `OPENAI_MODEL`도 설정할 수 있습니다.
4. Deploy 후 생성된 공개 URL을 학생들에게 공유합니다.
5. 학생에게 공유하기 전, 휴대전화에서 질문·답변·AI 피드백을 테스트합니다.

## 개인정보·비용 주의
- 학생 이름, 학교명/반, 연락처, 민감한 개인정보는 입력하지 않도록 안내하세요.
- API 사용료가 발생할 수 있으며, 공개 링크는 누구나 사용할 수 있으므로 사용량 제한·인증·요금 상한을 검토하세요.
- 배포 전 학생용 개인정보 안내 및 교내 정보보안 지침을 확인하세요.
